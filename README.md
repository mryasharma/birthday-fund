# Yash's Birthday Fund

A static, mobile-friendly birthday wishlist and UPI contribution page.

## Setup
1. Add your shoe image as `assets/shoes.jpg`.
2. Add your own UPI QR image as `assets/upi-qr.png`.
3. Open `script.js` and set `UPI_ID` to your UPI ID.
4. Change `VERIFIED_RAISED` only after verifying real payments.

## Publish with GitHub Pages
1. Create a **public** repository named `birthday-fund`.
2. Upload all files, keeping the `assets` folder.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish.

The site does not automatically verify UPI payments. The progress total is manually updated after payment confirmation. Do not publish private banking details, UPI PINs, or OTPs.
